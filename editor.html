Question Studio

Edit an existing question, or add a new one with at least 50 distinct answers. Put each answer on its own line, like 70 | Nintendo 64 | N64. The number is the score; extra names are accepted spellings. Use 10, 25, 45, 70, or 100.

Open GitHub to publish ↗

In GitHub, select all the existing text, paste your updated questions, then choose Commit changes. Only accounts with write access to the repository can publish. Drafts here are not saved until you publish.
